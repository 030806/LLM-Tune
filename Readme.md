# LLM微调实验：DeepSeek-R1-Distill-Qwen-7B 适配情感类任务
本仓库包含基于 DeepSeek-R1-Distill-Qwen-7B 模型针对情感类任务微调的完整代码、实验流程及评估结果，所有实验均可复现。

## 项目简介
本项目对 DeepSeek-R1-Distill-Qwen-7B 模型进行 LoRA 微调，重点优化模型在**简短指令、抽象概念、情绪表达**三类情感类输入场景下的生成效果，提升语义匹配度、格式规范性与共情表达能力。

## 环境配置
### 基础环境
- 操作系统：Linux
- 深度学习框架：PyTorch 2.15.0 + cuda124
- 硬件加速：NVIDIA GeForce RTX 3090
- Python 版本：3.10

### 依赖安装
```bash
# 创建conda环境
conda create -n llm-tune python=3.10
conda activate llm-tune

# 安装依赖
pip install -r requirements.txt
```

## 快速复现流程
### 1. 数据集预处理
将原始数据转换为训练所需格式，并划分训练集/验证集：
```bash
# 基础格式转换
python generated_converted_data.py

# 转换为SFT训练格式
python generated_stf_r1_data.py

# 划分训练集与验证集
python split_sft_r1_data.py
```
> 注意：运行前需将脚本中的数据集路径替换为本地实际路径。

### 2. 基础模型下载
下载 DeepSeek-R1-Distill-Qwen-7B 基础模型：
```bash
python download_model2.py
```
> 注意：运行前需将脚本中的模型下载路径替换为本地路径。

### 3. 模型微调
执行LoRA微调脚本：
```bash
python train_distill.py
```

### 4. 模型测试
输入自定义情感类问题测试模型效果：
```bash
# 示例：测试抑郁情绪相关回复
python test.py "我最近一直感到非常抑郁和绝望"

# 可替换为任意测试语句，如：
# python test.py "人生没有意义"
# python test.py "处理大量愤怒情绪"
```

### 5. 可视化界面启动
通过Streamlit启动可视化交互界面：
```bash
streamlit run ui.py
```

## 实验结果
### 核心指标对比
微调后模型在关键指标上实现显著提升：
| 指标类别       | 具体指标           | 基础模型 | 微调模型 | 变化率/提升率 |
|----------------|--------------------|----------|----------|---------------|
| 核心指标       | BLEU Score         | 0.0113   | 0.0554   | +391.6%       |
|                | ROUGE-1            | 0.2013   | 0.7503   | +272.8%       |
| 性能指标       | 平均生成时间(秒)   | 16.40    | 16.61    | +1.3%         |
|                | 平均响应长度(字符) | 951.2    | 856.0    | -10.0%        |
| 格式指标       | 推理格式正确率     | 0.0%     | 80.0%    | +8000.0%      |
|                | 答案格式正确率     | 10.0%    | 80.0%    | +700.0%       |
|                | 空响应率           | 0.0%     | 0.0%     | +0.0%         |

### 关键结论
1. 微调后模型语义匹配能力大幅提升，BLEU/ROUGE指标实现3倍以上增长；
2. 推理效率基本稳定（生成时间仅增加1.3%），输出内容更精炼（响应长度减少10%）；
3. 结构化输出能力突破式改善，推理/答案格式正确率提升至80%。

## 注意事项
1. 所有脚本运行前需检查并替换路径（数据集/模型/输出目录）为本地路径；
2. 微调过程建议在≥24G显存的GPU上运行，避免显存不足；
3. 若需调整微调参数（如学习率、LoRA秩、训练轮数），可修改`train_distill.py`中的配置项。
